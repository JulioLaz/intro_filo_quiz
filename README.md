# CHRONOS QUIZ — Del Arché a la Metafísica

Quiz interactivo de filosofía antigua con estética retro-arcade. Cubre el recorrido desde los filósofos presocráticos hasta la metafísica aristotélica.

## Descripción

Aplicación web de una sola página (`index.html`) que permite al jugador registrar su nombre, elegir una dificultad y responder preguntas de filosofía contra el reloj. Al finalizar muestra el puntaje y un ranking de desempeño.

## Niveles de dificultad

| Nivel | Tema | Preguntas | Tiempo por pregunta |
|-------|------|-----------|---------------------|
| ⚡ NOVATO | Presocráticos (Tales, Anaximandro, Anaxímenes, Heráclito, Parménides) | 8 | 20 s |
| ⚔ GUERRA | Sofistas y Sócrates (Empédocles, Atomistas, Sofistas, Sócrates, Platón) | 10 | 15 s |
| 🔥 SABIO | Aristóteles y Metafísica (Platón, Aristóteles, conceptos avanzados) | 10 | 10 s |

## Uso

Abrir `index.html` directamente en el navegador. No requiere instalación ni dependencias externas.

```
U1_T3_filo_intro_quiz/
└── index.html    # Aplicación completa (HTML + CSS + JS)
```
